# Quran Audio – قرآن صوتي

A React + TypeScript + Vite web application for browsing and streaming all 114 Surahs of the Holy Quran with renowned reciters, full Arabic RTL UI, Media Session integration, sleep timer, favorites, 3 themes, and a local developer dashboard.

## Scripts
- `npm run dev` — Start development server on port 3000
- `npm run build` — Type-check and build production bundle
- `npm run lint` — Run ESLint
